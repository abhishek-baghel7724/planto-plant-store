# Planto

A responsive indoor plant shop website built with HTML, CSS, and JavaScript.

## Pages

- `planto.html` — homepage and plant sections
- `more.html` — additional plant information
- `explore.html` — plant exploration page
- `small-desk-plant.html` — small desk plant details

## Run locally

Open the project folder in Visual Studio Code and start `planto.html` with the Live Server extension. You can also open the HTML file directly in a browser.

The pages share `planto.css`; the interactive features are in `planto.js` and `mobile-menu.js`.
